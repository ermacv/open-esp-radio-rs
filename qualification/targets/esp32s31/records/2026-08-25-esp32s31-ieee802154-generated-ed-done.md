## Qualified integration boundary

The probe no longer owns a handwritten ED-DONE pointer write. Its PAC
validation method calls the production `write_ed_done_selected_image()` lease
method, which calls the literal-only raw PAC function generated by Blobray from
the reviewed `[[selected-register-writes]]` fact. The generated function has no
caller-supplied register image and does not make the SVD register writable.

All three boots reproduced this relation while the CPU route remained detached
on both cores:

| Checkpoint | Value |
| --- | ---: |
| Active `EVENT_ENABLE` | `0x0150` |
| Active `RX_ABORT_ENABLE` | `0x03800000` |
| Latched `ED_DONE` plus TIMER0 | `0x0140` |
| After generated ED-DONE image `0x0040` | `0x0100` |
| After separate validation TIMER0 image `0x0100` | `0x0000` |
| Final `EVENT_STATUS` | `0x0000` |

No RX abort or STOP occurred. Event and abort enables returned to zero. This
qualifies the generated TOML-to-hardware path for exactly the ED-DONE selected
image under the same serialized transaction as the earlier record.

## Explicitly not proven

- full-register W1C semantics;
- writes for event bits other than the two separately tested images;
- concurrent arrival of the same event bit;
- active or level-triggered CPU interrupt routing;
- synchronous STOP behavior;
- production PHY/RF/BTBB readiness;
- a second ED transaction without reset.

The production finite-operation state machine may use this selected write only
after observing lone `ED_DONE`, and must require a full zero status readback
before returning reusable ownership. Repeated reuse still requires its own
back-to-back HIL scenario.
